## Development Setup

### Prerequisites
- **Node.js 22+** (required for Next.js 16 + Turbopack)
- **npm** (project uses `package-lock.json`, no Bun dependency)

### First-time setup
```bash
git clone https://github.com/Russia24x/AiCryptoDiscoveryFeed.git
cd AiCryptoDiscoveryFeed
npm install
cp .dev.vars.example .dev.vars  # Create local env file
npm run dev                      # Start dev server at http://localhost:3000
```

### Scripts
| Command | Description |
|---------|-------------|
| `npm run dev` | Start Next.js dev server (Turbopack) |
| `npm run build` | Next.js production build |
| `npm run build:worker` | OpenNext Cloudflare Workers bundle |
| `npm run deploy` | Build + deploy to Cloudflare Workers |
| `npm run lint` | ESLint |
| `npm run preview` | Build + local preview in workerd runtime |

## Code Style

### TypeScript
- **Strict mode**: `strict: true` in `tsconfig.json`
- **No `any` without justification** (ESLint `@typescript-eslint/no-explicit-any` is disabled but discouraged)
- **Path alias**: Use `@/` for `src/` imports (e.g., `import { cn } from "@/lib/utils"`)

### ESLint
The project extends `nextCoreWebVitals` + `nextTypescript`. Many rules are disabled (see `eslint.config.mjs` for the full list). Key points:
- `react-hooks/exhaustive-deps` is disabled — manually verify effect dependencies
- `react-hooks/set-state-in-effect` is disabled — but `useSyncExternalStore` is preferred over `useEffect + useState`
- `@typescript-eslint/no-unused-vars` is disabled — clean up unused imports manually
- `@next/next/no-img-element` is disabled — use `<img>` with `loading="lazy"` and `referrerPolicy="no-referrer"`

### Fonts
All fonts are **self-hosted** via `@fontsource` packages (no Google Fonts build-time fetch):
- `@fontsource/estedad` (weights 800, 900) — display headings
- `@fontsource/vazirmatn` (weights 300-900) — Persian body text
- `@fontsource/inter` (weights 300-900) — Latin/numbers
- `@fontsource/jetbrains-mono` (weights 400, 500, 700) — code blocks

Import per-weight CSS in `src/app/layout.tsx`. Font CSS variables are defined in `src/app/globals.css` `:root`.

### RTL Support
- Use **logical CSS properties** in Tailwind: `ms-`/`me-` (margin-inline-start/end), `ps-`/`pe-` (padding-inline-start/end), `inset-inline-start`/`inset-inline-end`, `start-`/`end-`
- The Logo component is `dir="ltr"` isolated — never mirrors
- Category names in the logo are always English (not translated)

### shadcn/ui Components
- Located in `src/components/ui/` (30 files)
- Do not edit — these are generated by `shadcn-ui` CLI
- If a component needs customization, create a wrapper in the parent directory

## Adding a New RSS Source

Edit `src/lib/sources/index.ts`:

```ts
{
  id: "my-source",
  name: "My Source",
  nameFa: "منبع من",
  url: "https://example.com/news",
  feed: "https://example.com/news/feed/",
  category: "space",  // "crypto" | "ai" | "tech" | "gaming" | "entertainment" | "space"
  language: "fa",     // "fa" | "en"
  icon: "newspaper",  // lucide-react icon name
  // Optional: if the site's category-specific RSS is broken (returns HTML),
  // use the main feed and filter by URL path:
  // pathFilter: "/space/",
}
```

### Category Type
```ts
type Category = "crypto" | "ai" | "tech" | "gaming" | "entertainment" | "space" | "all";
```

Note: `"social"` is a route (`/social`), NOT a feed Category. It has its own page and brand tint but no RSS sources.

## API Route Conventions

- All routes export `dynamic = "force-dynamic"` and `revalidate = 0`
- Use `fetchWithTimeout()` from `@/lib/fetch-with-timeout` for external fetches
- Use `createFallbackCache()` from `@/lib/fallback-cache` for in-memory cache (serves stale indefinitely)
- Use `isBlockedHost()` + `readBodyCapped()` from `@/lib/fetch-guard` for proxy routes
- Set `Cache-Control` header with `s-maxage` + `stale-while-revalidate`
- Return HTTP 200 even on error (so client can show fallback UI)

## TanStack Query Guidelines

- **Default**: `staleTime: 60s`, `gcTime: 10min`, `refetchOnWindowFocus: true`, `retry: 1`
- **Per-query overrides**: set `staleTime` based on data volatility (ticker 30s, market 2min, historical 30min)
- **Never use `refetchInterval`** — rely on `refetchOnWindowFocus` instead (reduces API calls ~75%)
- **Shared cache**: use the same `queryKey` across components that need the same data (e.g., `["channel", handle]` shared between ChannelsHub and SocialPortal)

## Git Rules (from RULES.md)

1. **NEVER force-push** — `git push --force` is absolutely forbidden
2. **Session-start sync check** — always `git fetch origin` + check divergence before starting work
3. **Token hygiene** — never commit tokens, never leave them in `.git/config`
4. **Pre-push safety net** — review `git log --oneline origin/main..HEAD` before pushing
